# Code & Character

One-page site for Code & Character, a digital product studio. Plain HTML/CSS/JS, no build step.

## Structure

- `index.html` — the site
- `assets/` — images and video used on the page
- `favicon.svg` — browser tab icon

## Deploying with GitHub Pages

1. Push this folder's contents to a GitHub repo (as the repo root, or a `docs/` folder, or a dedicated branch — whichever you configure in Pages settings).
2. In the repo, go to **Settings → Pages** and set the source to the branch/folder holding these files.
3. To use a custom domain, add a `CNAME` file at the root containing just your domain (e.g. `example.com`), and point your domain's DNS at GitHub Pages per [GitHub's custom domain docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).
